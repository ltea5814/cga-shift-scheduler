# 海洋委員會海巡署 - 輪值排班智慧管理系統 操作使用手冊

這是一套專門為**海巡署輪值單位**量身打造的單機網頁版智慧排班系統。
具備**免安裝、純前端、無公務資安外洩風險、符合公務人員請假規則、假日值日平衡演算法、同仁離線預報**與**一鍵導出 Excel/列印**等特性。

---

## 🌟 核心特色

1. **零安裝、開箱即用**：
   - 只要用滑鼠雙擊 [`index.html`](file:///c:/Users/ltea5/OneDrive/Desktop/AI/cga-shift-scheduler/index.html)，即可在 Chrome、Edge、Firefox 等任何瀏覽器中直接開啟。
   - 所有資料（名冊、請假、值日表）皆加密保存在使用者的本機瀏覽器（LocalStorage）中，**完全不經由外部伺服器**，100% 符合海巡署公務資安規範。

2. **公務人員休假規則全面鎖定**：
   - 內建假別：**輪休**、**慰休**（公務年資慰勞假）、**補休**（值班/加班衍生補休）、**病假**、**事假**、**公假/公差**（受訓/出庭/勤務），以及海巡專屬 **11月8日「海巡節休假」**。
   - 只要同仁登記休假或特別行程，智慧演算法**絕對不會**將該員排入當日值日。

3. **智慧公平排班演算法**：
   - **假日平均分配**：針對週六、週日與國定假日（如國慶、海巡節等）優先進行負擔平均演算，確保每位同仁在假日輪值的次數差異降到最低（極差 ≤ 1天）。
   - **總輪值天數均等**：全月總值日天數均勻分配。
   - **防連續值勤**：強制避免一人連續兩天值日。
   - **個人指定天數**：名冊內可為每位同仁設定本月值日天數，例如 1 天或 5 天；自動排班不會納入上月值日天數。

4. **辦公室同仁共同編輯與填報流程**：
   - **同仁端**：切換至「✍️ 同仁預假登記」標籤，點選自己的名字，在月曆上點擊要請假的日期與假別，點擊「📋 複製我的填報代碼」（或下載 `.json` 檔），貼在通訊軟體或公務信箱傳給排班同仁。
   - **排班幹部端**：在「📋 排班主管統整」頁面點擊「📥 批次匯入同仁登記」，將大家傳來的代碼全部貼上，一秒彙整所有人請假，接著點擊「✨ 智慧公平排班」，瞬間完成全月排班！

5. **正式公文格式報表導出**：
   - 點擊「📗 導出 Excel 排班表」：生成包含「海洋委員會海巡署 [單位] 輪值預定表」表頭、個人職稱、請假明細、值日天數統計、與【承辦人 / 科長 / 副主管 / 主管核定】簽核欄的標準 `.xlsx` 檔。
   - 點擊「🖨️ 列印預覽 / PDF」：自動排版為 A4 橫式（Landscape）公文送陳格式。

## 🚀 快速使用步驟

### 步驟一：開啟系統
直接前往 `cga-shift-scheduler` 資料夾，連按兩下 [`index.html`](file:///c:/Users/ltea5/OneDrive/Desktop/AI/cga-shift-scheduler/index.html)。

### 步驟二：確認或修改組內名冊 (滾動式調整)
點擊上方「👥 輪值人員名冊」標籤頁：
- 系統已預載 7 位同仁（組長、專員、科員、巡查員、查緝員、辦事員）。
- 您可點擊「➕ 新增輪值同仁」或點擊「編輯」修改姓名、職稱及本月指定值日天數。

### 步驟三：登記同仁特別行程或休假
- **方式 A（排班人員代為登記）**：在排班清單中直接點擊該日期的「＋請假」，選取同仁、假別及備註。
- **方式 B（同仁自行填報傳送）**：讓同仁開啟該網頁點「✍️ 同仁預假登記」，點選日期後產生代碼傳回，排班人員使用「📥 批次匯入」一次貼入。

### 步驟四：一鍵智慧排班與手動微調
1. 點擊頂部右上角「✨ 智慧公平排班」，系統演算法自動完成分配。
2. 若某天想指定特定同仁或換班，點擊該日「值日人員」格子即可手動調整或與其他日期對調。
3. 檢視下方「⚖️ 假日值日天數公平度分析」與「📈 全月總輪值天數分配」長條圖確認公平性。

### 步驟五：匯出與呈核
1. 點擊「📗 導出 Excel 排班表」獲取完整 Excel 表格。
2. 點擊「🖨️ 列印預覽 / PDF」可直接以 A4 橫印列印出紙本供長官簽核。

### 手機開啟方式
1. 將整個 `cga-shift-scheduler` 資料夾放到辦公室可連線的 HTTPS 靜態網站，或由辦公室電腦啟動簡易網頁伺服器，讓手機與電腦連同一個網路。
2. 手機用 Chrome／Safari 開啟 `index.html` 的網站網址；第一次開啟時請保持連線，讓系統完成離線快取。
3. Android Chrome 選「⋮ → 加到主畫面」；iPhone Safari 選「分享 → 加入主畫面」。之後可從手機桌面開啟，即使暫時沒有網路也能使用。
4. 不建議直接用手機檔案管理器開啟 `file://` 的 HTML，因為瀏覽器通常不允許 Service Worker，離線安裝與快取功能可能無法運作。

每日最低上班人數為 2 人。系統會在主畫面列出可上班人數不足的日期，執行智慧排班時也會再次警示，方便通知同仁協調改假。

### 匯入行政機關辦公日曆
若遇到政府公告的調整放假或補行上班，請到政府資料開放平臺下載「中華民國政府行政機關辦公日曆表」CSV。回到系統的「備份與說明」頁，使用「匯入辦公日曆 CSV」匯入。系統會依照 CSV 的「是否放假」欄位判斷：平日放假會標成假日，週六補班會改成上班日。

匯入後若有使用 Google 試算表同步，請再按一次「上傳到 Google 試算表」，讓手機與其他裝置讀到相同的辦公日曆設定。

Google 試算表同步的部署步驟請參考 [GOOGLE_SHEETS_SETUP.md](GOOGLE_SHEETS_SETUP.md)。

### 離線與手機使用
本工具已加入 PWA 離線快取。第一次請用 HTTPS 網站開啟，之後可在手機瀏覽器選擇「加入主畫面」，離線時仍可使用排班、請假與 Excel 匯出功能。

目前資料仍儲存在各裝置的瀏覽器中，因此離線時每支手機的資料彼此獨立，無法自動同步。建議由一位承辦人維護主檔，其他人透過個人填報代碼或 JSON 傳回，再由承辦人匯入整合。若要多人同時看到同一份資料，後續需要增加雲端或辦公室內網同步後端。
